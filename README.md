Descripción general
CineTicket es una plataforma web que permite a los usuarios consultar la cartelera de un cine, elegir función y horario, seleccionar sus butacas y comprar entradas de forma online, evitando las filas físicas en boletería.
Objetivo
Desarrollar una aplicación web funcional que integre front-end, back-end y base de datos, aplicando los conceptos vistos en la cursada: manejo de estado, persistencia de datos, autenticación de usuarios y lógica de negocio (disponibilidad de asientos, promociones, etc.).
Problema que resuelve
Evita filas y demoras en la compra presencial de entradas.
Permite ver disponibilidad de butacas en tiempo real.
Centraliza cartelera, horarios y promociones en un solo lugar.
Pagos seguros.
Funcionalidades principales
Visualización de cartelera (películas en cartel, próximos estrenos).
Detalle de película: sinopsis, trailer, duración, clasificación.
Selección de función día, horario y sala.
Sistema de cobro online.
Mapa interactivo de butacas (libres/ocupadas/seleccionadas).
Carrito y detalles de compras.
Confirmación de compra con entrada digital (QR).
Envío de entradas y comprobantes por email y whatsapp
Campañas de marketing
