**Nombre del proyecto:** Cine Concordia - Sistema web de venta de entradas online

### Integrantes

Leonardo Mover, Santiago Jacobo, Nazareno Rodriguez y Valentin Reboli.

### Descripción del proyecto

Cine Concordia será una plataforma web destinada a la gestión y venta de entradas online para un cine. El sistema permitirá a los usuarios consultar la cartelera, conocer la información de las películas, seleccionar una función, elegir el día, horario y sala, y seleccionar sus butacas mediante un mapa interactivo que mostrará la disponibilidad en tiempo real.

El proyecto contará con un sistema de compra online y generación de entradas digitales con código QR. También se utilizará **n8n** para automatizar el envío de confirmaciones de compra por **Telegram y correo electrónico**.

El objetivo principal es desarrollar una aplicación web completa que integre **front-end, back-end y base de datos**, aplicando los conceptos trabajados durante la cursada.

### Requerimientos

El sistema deberá cumplir con los siguientes requerimientos:

* Permitir a los usuarios consultar la cartelera y la información de las películas disponibles.
* Permitir seleccionar una película, función, día, horario y sala.
* Mostrar un mapa interactivo de las butacas de cada sala.
* Mostrar la disponibilidad de las butacas en tiempo real.
* Permitir seleccionar una o varias butacas disponibles.
* Evitar que dos usuarios puedan comprar la misma butaca para una misma función.
* Permitir realizar la compra de entradas de forma online.
* Generar una entrada digital asociada a cada compra.
* Generar un código QR para validar las entradas.
* Enviar automáticamente la confirmación de la compra mediante correo electrónico y Telegram utilizando **n8n**.
* Permitir la gestión de películas, funciones, salas, horarios y butacas por parte de los administradores.
* Registrar las compras y entradas en la base de datos.
* Contar con un sistema de autenticación y gestión de usuarios.
* Mantener la información del sistema centralizada en una base de datos.

### Problemas que resuelve

El sistema busca solucionar diferentes problemas relacionados con la gestión tradicional de un cine y la compra presencial de entradas:

* Reduce la necesidad de que los clientes se acerquen físicamente al cine para comprar sus entradas.
* Permite consultar la cartelera y los horarios desde cualquier dispositivo y en cualquier momento.
* Evita confusiones o errores al momento de asignar butacas.
* Permite conocer la disponibilidad de las butacas antes de realizar la compra.
* Reduce el riesgo de vender una misma butaca a más de un cliente.
* Centraliza la información de películas, funciones, salas, usuarios, compras y entradas.
* Automatiza el envío de confirmaciones, reduciendo tareas manuales por parte del personal.
* Facilita la validación de las entradas mediante códigos QR.
* Permite al personal del cine administrar la información del sistema desde una única plataforma.
* Mejora la experiencia de compra al permitir que el usuario pueda completar todo el proceso de manera online.
